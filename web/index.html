    Здоровье системы

    Проверка служб, конфига, портов, ресурсов, сети, файрвола, безопасности, резервных копий и обновлений. Проверки запускаются только кнопками ниже. Рядом с результатом, который можно исправить, появится кнопка «Исправить».

    Проверка стабильности соединения

    Сетевое оборудование на пути может останавливать TCP-соединения до вашего хостера: данные идут несколько пакетов и прекращаются. С сервера это не видно. Откройте созданную ссылку на телефоне в мобильной сети (VPN выключен): страница скачает файл 256 КБ с вашего сервера и пришлёт результат сюда. Идея проверки: stability-check.

    Каждое подключение – один протокол на своём порту. Пользователи получают сразу все включённые подключения одной ссылкой.

    Клиент подключается к вашему узлу в другой сети (например, в другой стране), а узел пересылает соединение на этот сервер. Ключи и трафик узлу недоступны: он только пересылает порты. Мост работает, только если адрес узла доступен из сети клиента: это проверяется замером с телефона, а не предполагается. Размещение узла в другой стране и его условия (в том числе у хостера) остаются на вашей ответственности.

    Ядра и компоненты

    Каждый протокол обслуживает своё ядро. Недостающее скачивается автоматически при создании подключения; здесь можно поставить заранее. Загрузки проверяются по SHA-256.

    Значки ядер принадлежат авторам проектов: Project X (Xray), SagerNet (sing-box), telemt, Amnezia (AmneziaWG). Значки mtg и Mieru нарисованы для панели.

    Параметры ядра Xray

    Журнал, DNS, маршрутизация, исходящие, политики и произвольный JSON. Изменения проверяются самим Xray перед применением, при ошибке остаётся прежний конфиг.

          Безопасность
        
    
        
    Смените пароль администратора для защиты системы.
    
        
    
          
          
        
    
        
    
          
          
        
    
        
      
    

    
    
      
    
        
        Двухфакторный вход
      
    
      
    Вход по паролю и одноразовому коду из приложения (Google Authenticator, Aegis, 2FAS…). Даже если пароль утечёт, зайти без телефона не получится.
    
      
    
        
    
        
        
    
        
      
    
      
    
        
    
        
    
        
      
    
      
    
    

    
    
      
    
        
        HTTPS панели
      
    
      
    Без HTTPS пароль и сессия идут по сети открытым текстом. С доменом панель получит бесплатный сертификат Let's Encrypt (нужен открытый порт 80 и домен, который смотрит на этот сервер).
    
      
    
        
    
      
    
        
    
        
    
      
    
      
    
        
    
        
    
      
    
      
    
        
    
        
      
    
      
    
    

    
    
      
    
        
        Адрес сервера
      
    
      
    IP или домен, который попадает в ссылки и подписки клиентов и в самоподписанный сертификат. Пусто – берётся адрес, по которому открыта панель.
    
      
    
      
    
    

    
    
      
    
        
        Маскировка
      
    
      
    REALITY выдаёт сервер за чужой сайт. Панель сама ищет подходящие сайты среди соседей по подсети сервера (нужны TLS 1.3 и HTTP/2). Прежний сайт ещё неделю принимается сервером, пока клиенты обновят подписку.
    
      
    
      
    
        
        
      
    
      
    
      
    
        
    
      
    
        
    Если домен смотрит на этот сервер, панель выпустит сертификат, поднимет страницу-заглушку и переключит на неё REALITY: чужой запрос получит ваш сайт, а не чужой. Нужна A-запись домена на этот сервер и свободный порт 80.
    
        
    
        
    
      
    
        
        
    
          
          
        
    
      
    
        Своя страница-заглушка
        
    
          
    Одна HTML-страница: стили и картинки внутри файла (CSS в <style>, картинки как data:). До 256 КБ. Её видит каждый, кто зайдёт на сервер по домену или по HTTP/3, поэтому не кладите туда ничего личного.
    
          
    
          
    
            
            
            
            
          
    
          
        
    
      
    
    
    

    
    
      
    
        
        Порты
      
    
      
    «Каждый протокол на своём порту» – по умолчанию. «Всё на 443» – панель занимает порт 443 и направляет трафик по имени сайта (SNI): REALITY, XHTTP, MTProto, а также WS/gRPC/VMess с собственным доменом. Остальные (UDP и протоколы без отдельного имени) остаются на своих портах.
    
      
    
        
    
      
    
    

    
    
      
    
        
        Оформление подписки

Расширенные возможности (кнопка «Продлить», информационный блок) нужны Happ и требуют Provider ID.
    
      
    
        
    
        
    
      
    
      
    
      
    
      
    
        
    
        
    
      
    
      
        
    
        
        
    
        
    
        
    
          
    
          
    
          
    
        
    
        
      
    
      
    
    

    
    
      
    
        
        Уведомления в Telegram
      
    
      
    Панель напишет вам, когда упало ядро, у пользователя закончился лимит или срок, кто-то превысил число устройств или вышла новая версия. Бота создайте у @BotFather, ID чата узнайте у @userinfobot.
    
      
      
    
      
    
      
      
    
        
    
          
    Свой ID покажет бот @userinfobot. Бот отвечает только им и только в личной переписке: статус, список пользователей, ссылка и QR, создание, продление, пауза. Команды: /help. Один токен одновременно может опрашивать только одна программа: на втором сервере или в тестовой копии панели возьмите другого бота.
    
      
    
      
    
      
    
        
        
      
    
    
    

    
    
      
    
        
        Обновление панели
      
    
      
    Текущая версия: —
    
      
    
        
        
      
    
      
    Обновления приходят из официального репозитория Kitsune. Перед установкой автоматически делается копия базы, проверяются контрольная сумма и подпись релиза. Прежний бинарник остаётся рядом как .old для отката.
    
    
    

      
    
        
    
          
          Резервное копирование
        
    
        
    Копия содержит пользователей, подключения, ключи и сертификат. Её можно развернуть на новом сервере (даже с другим IP): нужные ядра скачаются сами. Копия содержит секреты: храните её как секрет.
    
        
    
          
          
          
    С паролем файл шифруется (AES-256), без пароля его откроет любой, у кого он окажется. Пароль не восстановить: потеряете его, потеряете копию.

Для приложений по подписке

Эти правила приезжают в приложение вместе с подпиской (Clash Verge, FlClash, Mihomo, Stash, sing-box); остальные приложения получают обычный список ссылок. Сервисы, реклама и свои правила ниже общие: они действуют и в подписке, и в конфиге для роутера.

Включена схема групп как в шаблоне XKeen: у неё свой список сервисов. Для подписки берётся список из обычной схемы (снимите галочку «Схема групп как в шаблоне XKeen», чтобы увидеть его).

Сервисы
Дополнительно

По одной в строке: ТИП,значение,действие. Типы: DOMAIN, DOMAIN-SUFFIX, DOMAIN-KEYWORD, IP-CIDR, IP-CIDR6, GEOSITE, GEOIP. Действие: PROXY (по умолчанию), DIRECT или REJECT. Кириллические домены переводятся в punycode сами. Эти правила стоят ниже сервисов и выше re:filter.

XKeen по умолчанию ожидает vless-reality: менять стоит, только если вы правили правила вручную.
